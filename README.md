# Audió Szintetizátor

Az alábbi nagy házifeladat egy audió szintetizátort valósít meg.
A program beolvas egy adott MIDI és oscillátor configurációs fájlt,
miután minden MIDI gomblenyomásnál beleírja az adott oscillátornak
megfelelő hangot a végső PCM audió fájlba.

> [!note] Megjegyzés:
> Ez a gyakorlatban bőven komplikáltabb és az érthetőség kedvéért
> lett egyszerüsítve a folyamat. A folyamat pontos leírása a
> specifikációban illetve a dokumentációkban lesz teljesen kifejezve.
